# ft_strjoin

## Descripción
Reserva memoria y devuelve una nueva cadena, resultado de la concatenación de `s1` y `s2`.

## Mi Implementación
Para unir dos cadenas, primero calculo la longitud total necesaria sumando las longitudes de `s1` y `s2`. Reservo la memoria correspondiente y procedo a copiar primero el contenido de `s1` y, justo a continuación, el de `s2`. Termino la nueva cadena con un carácter nulo. Es una herramienta básica para la manipulación de textos dinámicos.
