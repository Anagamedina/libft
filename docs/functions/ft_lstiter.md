# ft_lstiter

## Descripción
Itera la lista `lst` y aplica la función `f` al contenido de cada uno de sus nodos.

## Mi Implementación
Implementé esta función como un iterador genérico. Recorro la lista desde el principio hasta el final con un bucle `while`. En cada nodo, ejecuto la función `f` pasándole como argumento el puntero al contenido. Esto permite realizar operaciones masivas sobre todos los elementos de la lista, como imprimirlos o transformarlos, sin tener que escribir la lógica de recorrido cada vez.
