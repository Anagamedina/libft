# ft_toupper

## Descripción
Convierte un carácter en minúscula a su equivalente en mayúscula, si el carácter es una letra minúscula.

## Mi Implementación
Implementé esta función verificando si el carácter recibido está dentro del rango de las letras minúsculas (de la 'a' a la 'z'). Si cumple la condición, le resto 32 para obtener el código ASCII de la letra en mayúscula. Es una operación aritmética directa y eficiente que aprovecha la organización estándar de los caracteres en C.
