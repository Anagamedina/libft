# ft_lstsize

## Descripción
Cuenta el número de nodos que contiene una lista.

## Mi Implementación
Para obtener el tamaño, simplemente inicializo un contador a cero y recorro la lista nodo por nodo. Por cada nodo que visito antes de llegar al final (`NULL`), incremento el contador. Es una operación sencilla pero muy útil para conocer la longitud de nuestras estructuras de datos dinámicas.
