# ft_isalnum

## Descripción
Comprueba si el carácter pasado por argumento es alfanumérico (letra o número).

## Mi Implementación
Para esta función, simplemente verifiqué si el carácter se encuentra en los rangos de las letras minúsculas ('a'-'z'), mayúsculas ('A'-'Z') o dígitos ('0'-'9'). Si cumple alguna de estas condiciones, devuelvo 1; de lo contrario, 0. Es una implementación sencilla que aprovecha el orden de la tabla ASCII.
