# ft_putendl_fd

## Descripción
Escribe la cadena `s` en el descriptor de archivo dado, seguida de un salto de línea.

## Mi Implementación
Para esta función, primero recorro la cadena carácter por carácter escribiéndolos en el descriptor de archivo. Una vez que he terminado de imprimir toda la cadena, realizo una escritura adicional para el carácter de salto de línea `\n`. Es una función muy práctica para imprimir mensajes de log o errores que deben aparecer en líneas separadas.
