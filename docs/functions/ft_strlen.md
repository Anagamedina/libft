# ft_strlen

## Descripción
Calcula y devuelve la longitud de la cadena de caracteres `str`, sin contar el carácter nulo terminador.

## Mi Implementación
Es la función más elemental de mi librería. Utilizo un contador de tipo `size_t` que se incrementa mientras recorro la cadena carácter por carácter hasta encontrar el `\0`. Es la base para casi todas las demás funciones que trabajan con cadenas.
