# ft_isprint

## Descripción
Comprueba si el carácter es imprimible, lo que incluye todos los caracteres que generan una salida visual, incluido el espacio en blanco.

## Mi Implementación
Validé que el carácter esté en el rango de 32 (que corresponde al espacio) hasta el 126. Si el valor cae dentro de este intervalo, podemos estar seguros de que el carácter se puede mostrar correctamente en la terminal.
