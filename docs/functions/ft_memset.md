# ft_memset

## Descripción
Llena los primeros `len` bytes del área de memoria `b` con el byte constante `c`.

## Mi Implementación
Para implementar `ft_memset`, convertí el puntero de entrada a `unsigned char *` y utilicé un bucle para asignar el valor `c` (también convertido a `unsigned char`) a cada posición de memoria. Es la función básica que utilizo para inicializar bloques de memoria con un valor específico de forma eficiente.
