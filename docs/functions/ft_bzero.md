# ft_bzero

## Descripción
Pone a cero (bytes nulos) los primeros `n` bytes del área de memoria apuntada por `s`.

## Mi Implementación
Mi implementación de `ft_bzero` utiliza un puntero a `unsigned char` para recorrer el área de memoria y asignar el valor `\0` a cada byte. Es una forma sencilla y efectiva de limpiar estructuras o buffers antes de su uso, asegurando que no contengan "basura" de ejecuciones anteriores.
