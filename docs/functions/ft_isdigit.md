# ft_isdigit

## Descripción
Comprueba si el carácter pasado por argumento es un dígito numérico (del '0' al '9').

## Mi Implementación
Implementé esta función verificando si el valor ASCII del carácter se encuentra entre el código de '0' y el de '9'. Es una herramienta esencial para cuando necesito parsear números desde una cadena de texto.
