# ft_isalpha

## Descripción
Comprueba si el carácter pasado por argumento es una letra del alfabeto (mayúscula o minúscula).

## Mi Implementación
Mi enfoque fue directo: comprobar si el valor ASCII del carácter está entre 'A' y 'Z' o entre 'a' y 'z'. Es la base para muchas otras validaciones de texto que realizamos en la librería.
