# ft_isascii

## Descripción
Comprueba si el carácter pertenece al estándar ASCII, es decir, si su valor está entre 0 y 127 inclusive.

## Mi Implementación
Aquí solo tuve que validar que el entero recibido esté en el rango de 0 a 127. Es una de las funciones más sencillas pero fundamentales para asegurar que estamos trabajando con caracteres estándar dentro del set ASCII de 7 bits.
